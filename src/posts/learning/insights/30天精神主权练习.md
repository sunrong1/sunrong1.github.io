# 30 天精神主权练习 — 把"内心为王"从口号变成日常

> 上一篇博客《阶层跃迁 5 年规划》写了"内心为王"的宣言。这篇是**具体到天的练习**。


## 一、设计原则


```
【核心】= 把"内心为王"从口号变成日常
【方式】= 每日 10 分钟 + 每周 1 实验 + 每月 1 反思
【不要】= 复杂仪式感（坚持不下来）
【要】= 微小可执行 + 立即见效
```

周主题（每天都有具体动作）

### 🟢 第 1 周（Day 1-7）= 觉察期

**主题**：意识到自己在"反应"还是在"选择"


## 三、每日 10 分钟模板

### 早晨 5 分钟（推荐：起床后）

```
【冥想 5 分钟】

1. 静坐 1 分钟
   - 闭眼，专注呼吸
   - 不评判任何想法

2. 问自己 3 个问题（每问 1 分钟）
   - 今天我要什么？
   - 什么在控制我？
   - 我能主动做什么？

3. 决定 1 件事（30 秒）
   - 今天我要"主动做"的 1 件事
```

### 晚上 5 分钟（推荐：睡前）

```
【反思 5 分钟】

1. 写 3 件事（每件 1 分钟）
   - 今天 1 个主动选择
   - 今天 1 个反应（被控制）
   - 今天 1 个洞察

2. 给明天 1 个建议（30 秒）
   - 明天我可以做"1 个主动选择"

3. 自我接纳（30 秒）
   - 今天我已经尽力了
   - 不完美 = 正常
```

## 九、为什么"精神主权"最重要

```
【传统阶层跃迁路径】
- 拼技能（学技术）
- 拼资源（攒钱）
- 拼关系（找人脉）

【缺失的一环】
- 拼心性（精神主权）
- 没有精神主权 = 学什么都是打工思维
- 没有精神主权 = 攒钱也守不住
- 没有精神主权 = 人脉也是被利用

【真正的"内心为王"】
- 我选择做什么
- 我选择不做什么
- 我选择如何做
- 我选择与谁同行
- 我选择何时停下来
```
