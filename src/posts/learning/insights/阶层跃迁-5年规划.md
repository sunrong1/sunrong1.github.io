# 阶层跃迁 5 年规划 — 从"优秀打工人"到"行业稀缺者"

> 本文写于 36 岁。这是我对自己后半生的宣言，也是具体可执行的路径图。


## 一、为什么要"超越普通人"？


不是因为鄙视普通人，而是因为**社会规则本身有阶层设计**。

普通人按部就班：读书 → 打工 → 买房 → 还贷 → 养娃 → 退休。这是被设计好的循环。

我想要**跳出这个循环*<!-- more -->
*——不是不工作，不是躺平，而是：

- 不被消费主义绑架
- 不被单一收入绑架
- 不被社会评价绑架
- 不被时间绑架

**真正的"为王"，是选择权在自己手里。**

## 三、社会给普通人设置的 10 大陷阱

### 陷阱 1：消费主义

- **表现**：名牌 = 身份，贷款 = 应该
- **真相**：资产 ≠ 负债，现金流 > 光鲜
- **我已脱离**：✅ 无房贷车贷，100 万现金，月支出 < 1 万

### 陷阱 2：单一收入来源

- **表现**：只靠工资，不敢投资 / 副业
- **真相**：工资是线性的，投资是复利的
- **我应做**：100 万投资（年化 5-8%）+ 副业 / 顾问

### 陷阱 3：学历崇拜

- **表现**：学历 = 能力，名校 = 成功
- **真相**：学历是敲门砖，能力 = 持续学习 + 输出
- **我的状态**：已上海 211 + 持续输出 105+ 篇博客

### 陷阱 4：35 岁焦虑

- **表现**：互联网不欢迎 35+
- **真相**：AI / 硬件 / 医疗 = 越老越值钱（稀缺性）
- **我的优势**：11 年硬件 + 5 年 AI = 跨界，36 岁正是经验顶峰

### 陷阱 5：必须买房

- **表现**：不买房 = 失败
- **真相**：资产 > 负债，现金流 > 房产
- **我的选择**：✅ 无房贷，100 万现金机会成本

### 陷阱 6：必须结婚生子（已选）

- **表现**：不结婚 = 异类
- **真相**：选择 = 自由
- **我的状态**：✅ 已婚 + 沐沐，家庭支持

### 陷阱 7：年龄 = 衰老

- **表现**：30 岁 = 老了
- **真相**：大脑 / 经验越来越强
- **我的体脂秤**：身体年龄 34 岁（实际 36 岁）= 比我年轻

### 陷阱 8：稳定 = 安全

- **表现**：铁饭碗 = 安全
- **真相**：行业风险 > 公司风险
- **我的状态**：表面稳定，实际部门生态位不好 = 隐性风险

### 陷阱 9：必须"卷"

- **表现**：996 = 应该
- **真相**：高效 ≠ 长时间，健康 = 长期价值
- **我的选择**：跳到 ISTJ 友好公司

### 陷阱 10：成功 = 单一标准

- **表现**：必须有钱有名有地位
- **真相**：成功 = 多维，内在满足 = 真实成功
- **我的"成功"**：家人幸福 + 自己自由 + 能力提升 + 内心为王

